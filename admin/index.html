🔑 GitHub ile Giriş Rehberi

GitHub Pages statik çalıştığı için doğrudan Personal Access Token (PAT) ile anında giriş yapabilirsiniz:

  1. Buraya tıklayarak GitHub'da token oluşturun.
  2. Note: "3dtasarimimalat CMS" yazın, repo kutusunu işaretleyip en alttan Generate token'a basın.
  3. Oluşan ghp_... kodunu kopyalayıp Sveltia CMS giriş ekranındaki "Personal Access Token" kutusuna yapıştırın.
✓ Token sadece tarayıcınızda saklanır ve bir daha sorulmaz. Tüm blog yazılarını ve site içeriklerini doğrudan düzenleyebilirsiniz.
