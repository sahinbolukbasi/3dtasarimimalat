3. Cloudflare menüsünden "SSL/TLS" sekmesine gidip modu "Full" veya "Full (Strict)" seçiniz ("Flexible" yapmayınız, döngüye girer).

3. ADIM ADIM CLOUDFLARE + GITHUB PAGES AKTİVASYONU
--------------------------------------------------------------------------------
1. Cloudflare'de yukarıdaki 5 kaydı ekleyin ve Proxy durumunun "DNS Only" (Gri) olduğundan emin olun.
2. Cloudflare sol menüden SSL/TLS -> "Full" seçeneğini seçin.
3. GitHub deponuza gidin: https://github.com/sahinbolukbasi/3dtasarimimalat/settings/pages
4. "Custom domain" kutusuna: 3dtasarimimalat.com yazıp Save deyin.
5. Birkaç dakika sonra DNS onaylanacak ve altındaki "Enforce HTTPS" kutusu aktifleşecektir. Kutuyu işaretleyin.
